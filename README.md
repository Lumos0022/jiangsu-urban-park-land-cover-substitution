# Land-cover substitution constrains the cooling potential of urban park greening

Figure-generation code for the manuscript:

> Chen, Y., Liu, Y., Wu, W., Liu, J., Zhang, C., Li, J., Wang, C., Hu, B. & Yao, Y. *Land-cover substitution constrains the cooling potential of urban park greening.* Submitted to Communications Earth & Environment.

## Overview

We examine how donor-cover availability constrains the model-projected cooling of urban park greening. In 1,034 parks across 13 cities in Jiangsu Province, China, six land-cover compositional parts (built-up, bare/sparse vegetation, trees, low vegetation, cropland, wet cover) are linked to daytime summer land-surface temperature (LST) from Landsat 8/9 (2019–2022, n = 728 complete cases) using isometric log-ratio (ILR) balances. Directional 10-percentage-point donor-to-recipient transfers are projected, each reported together with the number of parks meeting the donor-area requirement.

## Repository structure

This repository contains the **figure-generation scripts** used to produce Figs. 1–5 and Supplementary Figs. 1–2 in the manuscript. All scripts output vector PDF/SVG plus 600-dpi PNG, with `pdf.fonttype=42` (true fonts embedded).

```
figures/
```

| Script | Output |
|---|---|
| `redo_figures_topjournal.py` | Base topjournal design: Fig. 1, Fig. 2, Fig. 3, Fig. 4, Fig. S1, Fig. S2 |
| `gen_fig3_beautified.py` | **Fig. 3** (final, beautified substitution matrix) |
| `gen_fig4_alt_discrete.py` | **Fig. 4** (final, discrete tree scenarios) |
| `gen_fig5_prediction_robustness.py` | **Fig. 5** (final, prediction gains + B3 sensitivity) |
| `gen_figS1S2_fig2style.py` | **Fig. S1** (radial profile), **Fig. S2** (area interaction) |
| `gen_fig2_tiff.py` | Fig. 2 600-dpi uncompressed TIFF export |
| `finish_figures.py` | Figure assembly helper |
| `aggregate_transfers.py`, `aggregate_transfers2.py` | Transfer aggregation helpers |
| `paper_plot_style.py` | Shared matplotlib style (Arial, semantic palette) |

## Data sources

All input data are publicly available. This repository does not redistribute raw data; please download from the original providers:

| Dataset | Source | Access |
|---|---|---|
| Land cover (10 m, 2021) | ESA WorldCover 10 m v200 | https://worldcover2020.esa.int/ (Zenodo: https://doi.org/10.5281/zenodo.7254221) |
| Land surface temperature | Landsat 8/9 Collection 2 Level-2 | Microsoft Planetary Computer (https://planetarycomputer.microsoft.com/); STAC collection `landsat-c2-l2` |
| Night-time lights (2020 annual) | NOAA VIIRS DNB V1 monthly composites | Google Earth Engine (NOAA/VIIRS/DNB/MONTHLY_V1/VCMSLCFG) |
| Park boundaries | Baidu Maps POI | Crawled under the provider's terms of use; not redistributed |

The model input tables (coefficients, scenario projections, sensitivity coefficients) are generated by the analysis pipeline; the cleaned park-level dataset is available from the corresponding author on reasonable request.

## Reproduction

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. The figure scripts read locked CSV tables from the analysis pipeline. Adjust the root paths at the top of each script as needed.

3. Run in order:

```bash
python figures/redo_figures_topjournal.py
python figures/gen_fig3_beautified.py
python figures/gen_fig4_alt_discrete.py
python figures/gen_fig5_prediction_robustness.py
python figures/gen_figS1S2_fig2style.py
```
